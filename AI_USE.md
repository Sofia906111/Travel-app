AccessWay, the project made by group members of Project F for Introduction to Mobile Systems Project uses the following AI tools for assistance for the application:

### ChatGPT
ChatGPT has been used for challenge the assumptions about the project and to research about the TalkBack native Android accessibility options to make the app compatible with native Android accessiblity options.


### Figma Agent
Figma Agent has been used for mocking up the high contrast variation of the prototype mockup, however the high-contrast accessible version mockup had to be manually created due to not correct color scheme applied by the agent
